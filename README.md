# Python Data Structures and Algorithms Practice

A collection of core data structures and algorithms implemented in Python.

## Contents
- `linked_list.py` - Singly Linked List with append and traversal
- `stack_queue.py` - Stack (LIFO) and Queue (FIFO) implementations  
- `sorting.py` - Bubble Sort and Quick Sort
- `binary_search.py` - Binary Search (requires sorted array)
